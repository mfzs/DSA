# Algorithms

This directory contains Python implementations and explanations of fundamental algorithms, including:

- Sorting algorithms (e.g., bubble sort, merge sort, quick sort)
- Searching algorithms (e.g., linear search, binary search)
- Recursion and backtracking
- Greedy algorithms
- Divide and conquer
- Dynamic programming

Each algorithm will have its own file and may include example usage and time/space complexity analysis.
