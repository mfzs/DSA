# Fundamentals

This directory covers the foundational concepts required for Data Structures and Algorithms (DSA) in Python. Topics may include:

- Basic Python syntax and data types
- Time and space complexity (Big O notation)
- Recursion basics
- Problem-solving strategies
- Mathematical foundations (e.g., logarithms, combinatorics)

Use this section to strengthen your understanding of the essential building blocks before diving into specific data structures and algorithms.
