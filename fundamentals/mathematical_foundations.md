# Mathematical Foundations

Some math concepts are very useful in DSA. Here are a few basics:

## 1. Logarithms
- Logarithms (log) are the inverse of exponentiation.
- Common in algorithms like binary search (O(log n)).
- Example: log2(8) = 3 because 2^3 = 8.

## 2. Combinatorics
- Deals with counting, arrangements, and combinations.
- Example: Number of ways to choose 2 out of 4 items: C(4,2) = 6.
- In Python:
```python
import math
print(math.comb(4, 2))  # Output: 6
```

## 3. Probability
- Probability = (number of favorable outcomes) / (total outcomes)
- Useful in randomized algorithms and analysis.

## 4. Modular Arithmetic
- Often used in problems involving large numbers (e.g., calculating remainders).
- Example: (a * b) % m

---

A basic understanding of these concepts will help you in many DSA problems!
