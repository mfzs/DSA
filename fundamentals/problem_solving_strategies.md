# Problem-Solving Strategies

Solving DSA problems is about thinking logically and breaking problems into manageable parts.

## 1. Understand the Problem
- Read the problem carefully.
- Identify inputs, outputs, and constraints.

## 2. Break Down the Problem
- Divide the problem into smaller subproblems.
- Solve each part step by step.

## 3. Look for Patterns
- Recognize common patterns (e.g., sliding window, two pointers, recursion).

## 4. Plan Before Coding
- Write pseudocode or draw diagrams.
- Think about edge cases.

## 5. Test Your Solution
- Try different test cases, including edge cases.

## Example: Reverse a String
```python
def reverse_string(s):
    return s[::-1]

print(reverse_string("hello"))  # Output: 'olleh'
```

---

Practicing these strategies will help you become a better problem solver!
